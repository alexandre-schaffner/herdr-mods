# Product

## Register

product

## Users
Alex, one engineer running a whole engineering org of Claude Code agents from Herdr (a native terminal and agent desktop app). A perpetual master chat per repository coordinates one merge-queue manager and one manager per area of focus, each running its own team of subagents and unit sessions. Alex has HQ open all day beside terminals, glances at it between other work, and sits down with it for focused review sessions. Context: long sessions, often returning after hours away, light or dark theme following the system.

## Product Purpose
HQ is the person's desk over the master. It eliminates tasks, never judgement: the org does the chores, and HQ puts the decisions that only the person can make (outward-facing approvals, judgement calls) in front of them with everything needed to decide fast. It also answers "what is going on right now" at a glance, lets the person talk to the master or any manager with full Claude Code parity, steer the org (managers, charters, prompts, policy), explore memory, and see proxy and plan usage. Success: the person spends their attention only on decisions and direction, and never has to go digging through terminals to know the state of the org.

## Brand Personality
Calm, fast, live. A calm command center (quiet, dense, color only when something needs you) with keyboard-cockpit speed (every action one key away, crisp focus states) and a mission-control sense of live flow between agents. Its recap mode reads like a well-typeset morning briefing: a clear headline, prose summaries, generous whitespace.

## Anti-references
- Chat-app clone: the org reduced to message bubbles and a Slack-like feed. Conversation logs are timelines, not bubbles (the dedicated Chat view is the one place a conversation is the point).
- Grafana wall: charts, gauges and number tiles for their own sake. Numbers appear when they support a decision.
- Generic SaaS dashboard furniture: KPI hero tiles, identical card grids, uppercase eyebrows over every section.

## Design Principles
1. Judgement first: whatever waits for the person is the loudest thing on screen; everything else is quiet until it isn't.
2. State at a glance, detail on demand: one line answers "what's happening", a click answers "why".
3. Every action one key away: keyboard paths for navigation, review and steering, visible as hints.
4. Live, not loud: motion and color convey state changes (working, blocked, done), never decoration.
5. Trustworthy familiarity: standard affordances, one component vocabulary across views, follows the Herdr theme.

## Accessibility & Inclusion
WCAG AA contrast in both light and dark themes; status never conveyed by color alone (shape or label too); respects reduced motion (native animations only, state-driven); keyboard reachable.
